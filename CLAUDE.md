# bitladder: контекст для агентов

Этот файл читается Claude Code автоматически. Он даёт достаточный контекст, чтобы
начать работу без истории чатов. Подробности в `docs/`.

## Что это

Микро-проект для портфолио Валерия: исследование экстремальной оптимизации нейросетей
(квантование 32 → 1 бит, прунинг, дистилляция) с доведением до железа и короткой
публикацией. Вдохновлён статьёй ViT-1.58b (arXiv 2406.18051, тернарные веса, 8-битные
активации).

Проект связан с главным проектом портфолио, голосовым ассистентом **Костяном**
(анатомический скелет на Jetson Orin Nano Developer Kit, отдельный репозиторий
`skull-assistant`). Прикладная цель здесь: keyword spotting на микроконтроллере,
который слушает всегда и будит спящий Jetson по ключевому слову.

## Текущее состояние (2026-10-07)

Фаза 0, каркас. Написано, но ещё не прогонялось на GPU и не проверялось на данных KWS:

- `bitladder/quant/`: STE-квантователи весов (uniform k-бит с опцией LSQ, тернарный
  absmean по BitNet b1.58, бинарный по XNOR-Net), PACT-квантователь активаций,
  слои `QuantConv2d` / `QuantLinear`, функция `apply_quantization`.
- `bitladder/measure/`: размер модели в реальных байтах после упаковки битов плюс
  zlib; MACs и BOPs через hooks.
- `bitladder/models/`: `TinyCNN`, `TinyMLP` для MNIST.
- `sandbox_mnist/run.py` и `sweep.py`: один прогон и свип по лесенке.
- `audio/kws/`: каркас DS-CNN, log-mel без torchaudio, загрузчик Speech Commands v2
  (не проверен на реальных данных).
- `tests/`: юнит-тесты квантователей, упаковки, размеров, форм моделей.

Окружение с CUDA ещё не создано (conda не имел доступа к сети). Рецепт в
`environment.yml`. На машине есть CPU-окружение conda `depth` с torch 2.0.1, его хватает
для тестов и дымовых прогонов.

Что проверено 2026-10-07 в окружении `depth` (CPU): все 16 тестов проходят (pytest там не
установлен, тесты гонялись самодельным раннером с заглушкой `pytest.approx` /
`parametrize`); `sandbox_mnist/run.py` работает end-to-end для fp32, ternary и ternary +
PACT 8 бит. `TinyCNN(width=8)` с global average pooling учится медленно: после двух эпох
на 12k примеров около 80%, одной эпохи на 3k хватает только на 15–17%. Для осмысленных
чисел нужен полный датасет и 5+ эпох. Данные MNIST скачиваются в `data/` автоматически.

## Ключевые решения

Все решения в `docs/decision-log.md` (формат ADR). Коротко:

1. Структура «песочница → перенос»: MNIST как разогрев на день-два, затем KWS на
   Speech Commands v2 как основная песочница и цель деплоя.
2. Квантователи пишем сами на PyTorch (не Brevitas / torchao).
3. Размер считаем в байтах после упаковки битов с масштабами и смещениями fp16;
   параметры и «теоретические биты» только как справка.
4. Jetson будится импульсом на пин 12 хедера J14 (кнопка питания). Кандидат MCU:
   STM32 Discovery B-U585I-IOT02A (пока предложено, не куплено).
5. Speech enhancement в бэклоге, нейросеть на FV-1 как отдельный спин-офф.

## Соглашения

- Документация и decision-log на русском. Код, идентификаторы и комментарии в коде на
  английском.
- Новое решение = новая запись ADR в конце `docs/decision-log.md` с датой. Старые записи
  не редактируются, а меняют статус.
- Каждый эксперимент пишет JSON в `results/` (в git не входит). Сводные таблицы и
  графики для публикации складываются в `docs/results/` (пока нет).
- Модели собираются из `QuantConv2d` / `QuantLinear` сразу, квантование включается
  через `apply_quantization(model, QuantConfig(...))`. Первый и последний слой по
  умолчанию остаются в 8 битах, вход первого слоя не квантуется.
- Совместимость с torch >= 2.0, без torchaudio.

## Как запускать

```bash
pip install -e ".[dev]"
pytest -q
python sandbox_mnist/run.py --scheme fp32 --epochs 2
python sandbox_mnist/run.py --scheme ternary --abits 8 --epochs 2
python sandbox_mnist/sweep.py --epochs 3
```
